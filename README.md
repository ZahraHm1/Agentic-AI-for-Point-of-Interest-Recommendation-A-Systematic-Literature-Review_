# Agentic-AI-for-Point-of-Interest-Recommendation-A-Systematic-Literature-Review_
This repository contains the full extraction dataset for our systematic literature review "Agentic AI for Point-of-Interest Recommendation: A Systematic Literature Review", conducted following the Kitchenham protocol (Kitchenham, 2004).

The review covers 135 primary studies published between January 2016 and July 2026, each classified on a six-level Agentic Capability Level (ACL) scale, from non-agentic neural predictors (L0) to fully autonomous systems that update their own memory across sessions without retraining (L5).
